# Cuicatl v0.1 measurement-scope decision

Date: 2026-10-11  
Status: accepted product-scope decision

## Decision

Cuicatl v0.1 will treat **device measurement · absolute SPL not calibrated** as
the normal measurement state unless solid calibration evidence exists for the
actual input chain.

Physical acoustic calibration is **not a v0.1 release blocker**.

Cuicatl will continue to make the best technically characterized digital
measurement available from Android while avoiding claims that the result is a
calibrated sound-pressure level.

## Rationale

Cuicatl is intended to run on more than the Samsung Galaxy J8. Root access,
vendor audio archaeology, and device-specific low-level investigation cannot be
assumed for every supported Android device.

The J8 investigation was still valuable because it established the limits of
what Android/device evidence can prove. It does not establish an absolute SPL
calibration for arbitrary phones.

Requiring the project owner to build or maintain an acoustic laboratory would
also move the project away from its intended software-analysis scope.

## v0.1 measurement contract

For an input without reliable absolute calibration evidence, Cuicatl may
provide:

- A- and Z-weighted digital levels in dBFS;
- current interval level, minimum, maximum and energy-equivalent level;
- sample peak and clipping evidence;
- fixed capture configuration for a session;
- actual routed-input provenance;
- timing/session history;
- durable session storage and portable export.

It must not label those measurements as calibrated absolute SPL.

The normal user-facing state is:

```text
Device measurement · absolute SPL not calibrated
```

## External inputs

External microphones are first-class inputs even when uncalibrated.

An uncalibrated USB, wired analog/TRRS, or Bluetooth microphone remains a
device measurement. Input identity and actual Android routing are preserved as
session provenance.

The J8 P3/TRRS path has been validated separately: Android automatically routed
capture from the built-in microphone to the wired headset microphone, and
Cuicatl interrupted the session when the route changed during capture.

Bluetooth-specific behavior remains deferred until suitable hardware is
available.

## Future calibration authorities

Calibration remains an optional future capability and is not discarded.

Two calibration authorities are anticipated:

1. **Manufacturer profile** — for a factory-calibrated external microphone when
   the manufacturer supplies suitable device-specific response and, where
   applicable, absolute sensitivity data.
2. **Physical reference** — the existing rootless reference workflow for a
   user who actually has suitable acoustic reference equipment.

A manufacturer-profile workflow must not require the user to recreate the
manufacturer's acoustic laboratory work.

A physical-reference workflow remains evidence-gated and must never be
satisfied with synthetic values.

## Root policy

Root access is not a Cuicatl runtime requirement and is not a calibration
requirement.

Root may be used on a dedicated laboratory device for platform archaeology, but
Cuicatl must remain useful on ordinary non-rooted Android devices.

## Consequence for v0.1

The critical path returns to sound-analysis usability:

```text
capture integrity
→ input provenance
→ Meter usability
→ history/export usability
→ robustness validation
→ v0.1 release
```

Physical absolute-SPL calibration can be added later when real evidence or a
factory-calibrated external microphone becomes available.
